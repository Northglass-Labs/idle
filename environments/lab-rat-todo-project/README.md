# Sample Todo Project

A small, dependency-free todo app copied into each local Idle development
environment. Open `index.html` in a browser; tasks are stored in localStorage.

## Files

- `index.html` — app shell
- `styles.css` — layout and theme
- `app.js` — todo logic and localStorage persistence
- `CONTRIBUTING.md` — contribution guidance

## Known issues (intentional)

- The "Done" filter is broken — shows all items instead of only completed ones
- No dark mode
- No tests or test framework
- No keyboard shortcuts
- Delete has no confirmation

These provide a simple, self-contained change target for contributors.

## How to use

Open `index.html` directly in a browser. No installation or build step is
required.
